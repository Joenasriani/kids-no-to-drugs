# Hero Mission: The Healthy Choice

**Game lineage:** Kids: No to Drugs / Hero Mission  
**Status:** canonical public source repository  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

Hero Mission: The Healthy Choice is an educational browser quiz game for children about drug, vaping, medicine and peer-pressure safety choices.

## Lineage

Historical labels include **Kids: No to Drugs**, **The Hero Mission** and **No-Drug Game**.

`Joenasriani/kids-hero-quest` contains an earlier visual/build variant of the same game. It is not a separate game lineage.

## Gameplay

Players complete ten randomly selected safety challenges, choose between two responses, receive short feedback and finish with a mission score and briefing.

Existing branches and historical files are retained as development history.
